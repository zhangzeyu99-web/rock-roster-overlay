# 阵容叠加器完整直播流程

## 1. 开播前准备

1. 打开“阵容叠加器”，确认顶部显示“本地服务”。
2. 进入“素材”，确认素材数量正常；缺素材时先导入素材文件夹。
3. 在左上“项目预设”选择本场比赛；新比赛建议新建一个预设，避免覆盖旧设置。
4. 切换项目预设会立即同步到 OBS 浏览器来源、采集窗口和 PNG 导出。
5. “实时同步到 OBS 和自动保存”默认保持开启。需要提前排下一局阵容时再关闭，确认后点“同步当前改动”。

## 2. 填阵容

1. 进入“阵容”。
2. 在“快速导入阵容”粘贴 6-12 个精灵名，支持换行或逗号分隔。
3. 确认匹配结果无缺失后，选择“填充左队”或“填充右队”；超过 6 个时会从起始队继续填到另一队。
4. 逐个检查形态、首领化、属性和战败状态。
5. 右侧缺失提示必须清空；有缺失就回到素材库补图或改名。

## 3. 调直播画面

1. 只要阵容条：预览切到“透明阵容”。
2. 需要整套直播间：进入“装修”，使用“比赛预设”或“自由模式”。
3. 文本框直接在预览里拖动、缩放；右侧调字体、字号、字重、颜色。
4. 调位置时可以打开“直播间辅助线”，开播前关闭。
5. 阵容整体偏上或偏下时，到“阵容 > 卡片设置”调整“上下位置”；左右队会同步移动。
6. 预览始终按 `1920 x 1080` 等比例缩放；OBS 和 PNG 应与预览一致。

## 4. 接 OBS

推荐使用 OBS “浏览器”来源：

| 用途 | 地址模式 | OBS 宽高 |
| --- | --- | --- |
| 左队阵容 | `mode=left` | `420 x 1080` |
| 右队阵容 | `mode=right` | `420 x 1080` |
| 双方阵容 | `mode=overlay` | `1920 x 1080` |
| 直播间装修 | `mode=room` | `1920 x 1080` |

操作：

1. 进入“直播”。
2. 在“OBS 采集”里复制对应地址。
3. OBS 新建“浏览器”来源，粘贴地址。
4. 按上表设置宽高。
5. OBS 画面不更新时，先确认应用里实时同步已开启，再刷新 OBS 浏览器来源。

透明窗口采集作为备用方式：

1. 在“直播”里打开对应采集窗口。
2. OBS 使用“窗口采集”选择该窗口。
3. 开启“窗口不挡鼠标”时不影响桌面操作；关闭后可以拖动窗口，右键关闭。

## 5. 直播中操作

1. 临时换精灵：在“阵容”改名字或用快速导入重填。
2. 首领化或退化：在槽位旁的形态下拉框切换。
3. 战败：勾选槽位“败”，画面只让精灵立绘变灰，名字和属性保持清晰。
4. 不想立即给 OBS 看：关闭实时同步，改完后点“同步当前改动”。
5. 当前画面需要留档：到“直播”导出 PNG。

## 6. 赛后收尾

1. 导出双方透明 PNG 或直播间 PNG。
2. 点击“打开导出位置”检查文件。
3. 下一场比赛新建项目预设，保留本场配置。
4. 不再需要的窗口用“关闭透明窗口”收掉。

## 开播前检查单

- 素材数量正常，缺失名单为空。
- 左队和右队都填满 6 个。
- 形态、首领化、战败状态已确认。
- 预览模式与 OBS 采集模式一致。
- OBS 宽高与采集模式一致。
- 直播间辅助线已关闭。
- 已导出一张 PNG 备份。
