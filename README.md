# 洛克王国世界阵容叠加器 v3.5.0

面向 OBS 直播场景的桌面阵容叠加器，支持双队精灵阵容、比赛信息、透明采集、直播间装修与 PNG 导出。

## v3.5.0 更新

- 新增并打磨三套 S3 赛季计分栏，默认使用“四叶合页”样式。
- 计分栏支持宽度、选手名和比分字号自由调整，并适配 720p、1080p、1440p 预设。
- 优化中央 VS/赛制区域的字号、留白与垂直居中。
- 默认隐藏标题图和双方头像，保留按需显示与素材选择能力。
- 保留新版弧形与旧版垂直阵容排布，旧配置可继续导入。

## 快速使用

1. 安装并打开“阵容叠加器”。
2. 在“阵容”里填写左队、右队 6 只精灵名；也可以从素材库拖到槽位。
3. 在“装修”里编辑直播间背景、标题、选手名、比分和自由文本框。
4. 在“直播”里复制 OBS 地址，或导出 PNG。
5. 导出完成后点击“打开导出位置”查看文件。

完整开播步骤见 [docs/live-workflow.md](docs/live-workflow.md)。

## OBS 地址说明

OBS 新建“浏览器”来源，把对应地址粘进去：

- 左队：只采集左侧 6 只阵容，建议 `420 x 1080`。
- 右队：只采集右侧 6 只阵容，建议 `420 x 1080`。
- 双方：采集左右两队透明阵容，建议 `1920 x 1080`。
- 直播间：采集背景、标题、选手名、比分、自由文本和两队阵容，建议 `1920 x 1080`。

编辑器保存后，OBS 浏览器来源会自动刷新当前画面。

## 直播间装修

- 比赛预设：包含大标题、左右选手名、左右比分。
- 自由文本：支持新增文本框，并在预览里拖动、缩放。
- 文本样式：支持字号、字重、对齐、文字颜色、底色、圆角、透明度。
- 辅助线：在“装修”里打开“直播间辅助线”，可显示居中线或居中线 + 安全框。辅助线会同步显示在 OBS 本地网页和采集窗口里，调完布局后关闭即可。
- 背景：可使用内置背景、导入自定义背景或隐藏背景。

## 透明窗口采集

“直播”页可打开采集窗口：

- 开启“窗口不挡鼠标”时，窗口不会拦截桌面操作。
- 关闭“窗口不挡鼠标”后，可拖动采集窗口画面，右键可关闭窗口。
- OBS 里使用“窗口采集”选择对应窗口即可。
