# S4 精灵衬板 A/B/C 方案

三方案现已全部接入项目。入口：阵容 → 阵容显示微调 → 底框，直接选择 S4 · A 月环留白、S4 · B 星轨横签或 S4 · C 月窗徽章。默认 A；保留 S3、纯透明与矩形选项。发布验收见 [v3.6.4](../../release-v3.6.4.md)。

| 方案 | 方向 | 取舍 |
| --- | --- | --- |
| A 月环留白 | 柔和月面、边缘减弱，优先突出精灵 | 赛季装饰较少，推荐作为克制方向 |
| B 星轨横签 | 只衬身体中下部，轮廓自然外露 | 最轻量，但对浅色精灵上半部的衬托较弱 |
| C 月窗徽章 | 浅拱窗轮廓、细蓝边与月纹 | 辨识度最高，六张纵排的框感也最明显 |
